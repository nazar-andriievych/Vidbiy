# Відбій

Android-будильник, який не дзвонить, поки у вибраному регіоні триває повітряна тривога,
і дзвонить після відбою. Якщо даних про тривогу немає — дзвонить як звичайний будильник.

**Завантажити:** https://nazar-andriievych.github.io/Vidbiy/ (Android 8.0 і новіші, APK —
у [Releases](https://github.com/nazar-andriievych/Vidbiy/releases)).

«Відбій» не попереджає про тривогу: його завдання — дати поспати, поки вона триває.
Безкоштовно, без реклами, реєстрації, геолокації й аналітики.

## Як це влаштовано

```
api.ukrainealarm.com ──► проксі (Cloudflare Workers) ──► телефон
```

- **Проксі** (`server/`) приймає вебхуки ukrainealarm і щохвилини бере повний знімок тривог.
  Віддає стан усієї країни, тож не знає, який регіон цікавить телефон. Ключ API — лише тут.
- **Застосунок** у момент будильника питає проксі й сам перевіряє свій регіон. Тривога є — мовчить
  і чекає відбою, перепитуючи кожні 30 с.
- **Fail-safe:** немає зв'язку, дані старші за 3 хв чи щось пішло не так — будильник дзвонить.

Детальніше: [вимоги](docs/requirements.md), [контракт проксі](docs/proxy-api.md),
[проксі](server/README.md).

## Збірка

Kotlin, Jetpack Compose, Material 3. Потрібні JDK 17+ і Android SDK.

```
./gradlew assembleDebug   # debug APK (встановлюється як ua.vidbiy.app.debug)
./gradlew test            # unit-тести
```

Release-збірка підписується ключем автора й без нього не збирається — див. [docs/release.md](docs/release.md).

| Тека | Що там |
|---|---|
| корінь, `app/` | Android-застосунок |
| `server/` | проксі на Cloudflare Workers (TypeScript) |
| `site/` | сторінка завантаження (GitHub Pages) |
| `docs/` | вимоги, дизайн, тестування, випуск |
| `tools/` | генерація довідника регіонів і резервного звуку |

## Дані

Тривоги — з офіційного API застосунку «Повітряна тривога» (api.ukrainealarm.com).
«Відбій» — незалежний некомерційний проєкт і не пов'язаний з розробниками «Повітряної тривоги».
