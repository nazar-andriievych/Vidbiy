# Відбій — специфікація дизайну (Android, Jetpack Compose)

Джерело: канвас «Відбій — Android», стан на 2026-09-27.
Разом із цим файлом:

- `screens/` — PNG кожного екрана і стану, світла й темна тема (`<екран>--<стан>--<light|dark>.png`). **Звіряйся з ними.**
- Тема (`Color.kt`, `Type.kt`, `Shape.kt`, `Theme.kt`) уже перенесена в застосунок: `app/src/main/java/ua/vidbiy/app/ui/theme`.
- `source/` — вихідні `.dc.html` (HTML з inline-стилями). Туди дивитися, якщо в цьому файлі бракує точного значення.
- Поведінка — у `docs/requirements.md` (номери FR нижче посилаються на нього).

Одиниці: 1 px у макеті = 1 dp (текст — sp). Макет намальований під ширину 390 dp; верстка має бути гумовою, без фіксованої ширини.

**Спрощення 2026-09-29.** Після порівняння з годинником Samsung екрани стали лаконічнішими (розділ 0).
PNG списку, редагування, очікування, дзвінка й налаштувань цього ще не відображають — де PNG і текст
розходяться, правильний текст.

## 0. Принципи лаконічності (2026-09-29)
1. **Спершу головне, деталі — глибше.** Список показує, як упізнати будильник. Редагування — значення. Варіанти й пояснення — у нижній панелі (bottom sheet), що відкривається натиском на рядок.
2. **Стандартні значення не показуємо.** Пауза 0, без крайнього часу — на картці нічого не пишемо; заданий крайній час — коротко біля часу.
3. **Один факт — в одному місці.** Не повторювати те саме в таблиці й у реченні поруч.
4. **Стан — лише коли щось не так.** «Оновлено …» з'являється лише тоді, коли дані застаріли.
5. **Пояснення — там, де вибирають.** Під полями редагування немає навчальних абзаців; пояснення — в нижній панелі поруч із варіантами. На екрані редагування лишається одне речення про результат («план»).
6. **Відсутність — це відсутність.** Звичайний будильник не має рядка «тривоги не враховуються» — у нього просто немає місця.

## 1. Основи

### 1.1 Кольори
Усі значення — у `ui/theme/Color.kt`. Зведення ролей:

| Роль у макеті | Material 3 | Де |
|---|---|---|
| bg | `background`, `surface` | фон екранів |
| s1 | `surfaceContainer` | картки, NavigationBar, поле пошуку |
| s2 | `surfaceContainerHigh` | діалоги, меню, кружечки іконок |
| s3 | `surfaceContainerHighest` | трек вимкненого Switch |
| text / text2 | `onSurface` / `onSurfaceVariant` | основний / вторинний текст |
| text2 як контур | `outline` | outlined-кнопки, чипи, сегменти |
| outline | `outlineVariant` | роздільники |
| primary | `primary` | заповнені кнопки, вибраний чип, увімкнений Switch |
| pc / onPc | `primaryContainer` (+ `secondaryContainer`) | тональні кнопки, вибраний сегмент, індикатор навігації, FAB |
| red*, yel*, warn | `MaterialTheme.alertColors` | усе, що стосується рівнів тривоги |

Правила кольору тривог:
- **Червона** (ракетна загроза): крапка `red`, контейнер `redContainer` / `onRedContainer`.
- **Жовта** (дронова загроза): `yellow`, `yellowContainer` / `onYellowContainer`.
- «Будь-яка» позначається двома крапками: червона + жовта.
- Колір **ніколи не єдиний носій інформації**: поруч завжди текст («Червона тривога · ракетна загроза»).
- Жовтий контейнер також означає попередження «Немає зв'язку з сервісом».
- Dynamic color вимкнений.

### 1.2 Типографіка
Шрифт **Onest**, вшитий у застосунок (див. `Type.kt`). Шкала **14 / 16 / 18 / 22 / 28** плюс час.

| Стиль | Розмір / вага | Використання |
|---|---|---|
| `displayLarge` | 88 / 400, −0.04em | час на редагуванні й екрані дзвінка |
| `displayMedium` | 56 / 400, −0.04em | час у картці будильника |
| `displaySmall` | 52 / 400 | поля годин/хвилин у виборі часу |
| `headlineMedium` | 28 / 500 | заголовки вкладок («Будильники», «Мої місця», «Налаштування») |
| `titleLarge` | 22 / 500 | заголовки підекранів, діалогів, станів («Чекаю на відбій тривоги») |
| `titleMedium` | 18 / 600 | заголовки карток-секцій («Відкласти дзвінок на», «Тема») |
| `titleSmall` | 16 / 600 | заголовки рядків («Розбуди після відбою», назва місця в списку) |
| `bodyLarge` | 16 / 400 | основний текст, план («Задзвоню через 5 хв після відбою.») |
| `bodyMedium` | 14 / 400 | вторинний текст, підказки під полями |
| `labelLarge` | 16 / 600 | кнопки |
| `labelMedium` | 14 / 500 | підписи над полями (колір `onSurfaceVariant`), підписи навігації |
| `labelSmall` | 14 / 600 | чипи рівня тривоги |

Час — **пропорційні цифри** (не `tnum`), інакше навколо «1» з'являються дірки.
Жирне (600) — тільки заголовки й кнопки. Підписи полів — 500 і сірі.
Мінімальний розмір тексту — 14 sp.

### 1.3 Форми й відступи
Див. `ui/theme/Shape.kt` → `VidbiyShapes`, `Dimens`.
- Картки будильників/місць: радіус 24, відступ 16–20, між картками 12.
- Картки-секції налаштувань і діалоги: радіус 28, відступ 20–24.
- Кнопки, чипи, сегменти — повністю округлі.
- Горизонтальний відступ екрана 16.
- Мінімальна зона натиску 48×48 (кнопки-іконки 48, кнопки дій ≥ 44 заввишки).

### 1.4 Іконки
Лінійні (stroke 2, заокруглені кінці), 24 dp; у рядках 18–22.
Можна брати Material Symbols Rounded (Outlined, weight 400) — близькі за стилем.
Відповідність: будильник → `alarm`, місце → `location_on`, налаштування → `tune`, маленька іконка сповіщення — `ic_stat_vidbiy` (силует іконки застосунку: будильник з галочкою); на головному екрані іконки разового режиму немає, не пісочний годинник — він читається як таймер, крайній час → `schedule`, немає зв'язку → `cloud_off`, живлення → `power_settings_new`, мапа («Усі області») → `map`, скасувати дзвінок → `notifications_off`, дозволи: `notifications`, `alarm`, `smartphone`/`lock`, `battery_full`.

## 2. Спільні компоненти

**NavigationBar** (3 пункти, з підписами): Будильники · Мої місця · Налаштування. Висота 80, фон `surfaceContainer`, індикатор 64×32 `secondaryContainer`, активний підпис 700, неактивні 500 `onSurfaceVariant`.

**Кнопка «+» у заголовку вкладки** (замість Extended FAB, 2026-09-29): іконкова кнопка 48 праворуч від заголовка «Будильники» / «Мої місця», як у годиннику Samsung. `contentDescription` — «Новий будильник» / «Додати місце». FAB більше не закриває останню картку.

**Картка будильника** (`01-alarms--list`; спрощено 2026-09-29 — без роздільника й нижнього блоку):
- час (`displayMedium`; якщо вимкнений — колір `onSurfaceVariant`), під ним **один рядок** (`bodyMedium`, сірий): дні, а якщо «враховувати тривоги» — ` · ` іконка місця 16 + назва місця + крапки рівня. Праворуч Switch (M3). Натиск на картку → редагування.
  Для TalkBack крапки мають опис («будь-яка тривога» / «лише червона»). Крайній час, якщо заданий, — праворуч від часу по базовій лінії: «до 08:00», `titleLarge`, `onSurfaceVariant` (для TalkBack «крайній час 08:00»). Пауза на картці не показується — вона на екрані редагування. Звичайний будильник — лише дні. Без регіону — «Регіон не обрано» замість назви місця.
  Увімкнений одноразовий будильник замість «Один раз» показує «Один раз · сьогодні» / «Один раз · завтра» (рішення 2026-09-29).
  Будильник з датою (FR-1a) — «Один раз · пт, 9 жовт.» (сьогодні/завтра — словами; рік — лише якщо не поточний), навіть вимкнений.
- після збереження будильника — Snackbar «Спрацює завтра о 06:45» / «сьогодні о …» / «у понеділок о …»; далі ніж за 6 днів (будильник з датою) — «9 жовтня о …». «Спрацює», а не «задзвонить»: будильник, що враховує тривоги, може почати чекати відбою.

**Рядок «Розбуди після відбою»** — стани в розділі 4.

**Картка будильника, що чекає відбою** (рішення 2026-09-29, дії перенесено 2026-10-03): світч прихований, час — звичайним кольором (навіть якщо одноразовий будильник уже зняв «увімкнено»), крайній час — як завжди, біля часу. Нижня частина картки замінюється **панеллю очікування** — вона ж і є місцем дій FR-18, окремого екрана очікування немає (3.8):
- радіус 16, відступ 16, контейнер рівня (`redContainer`/`yellowContainer`; під час паузи — `primaryContainer`; поки перевіряє — `surfaceContainerHigh`);
- крапка 12 (у паузі — `schedule` 20), «Чекає відбою» / «Відбій · задзвоню о 07:17» / «Перевіряю тривогу…», під ним «Червона тривога · Дім» (+ «оновлено 3 хв тому», лише коли даним понад 120 с);
- третій рядок — лише якщо він щось додає: «Задзвоню через 5 хв після відбою» (пауза > 0, стан «тривога»), «Якщо тривога не почнеться знову» (пауза після відбою), або `cloud_off` + «Немає зв'язку з сервісом. Якщо дані не оновляться ще хвилину — задзвоню» (даним понад 120 с; замінює два попередні);
- ряд із двох кнопок по 48 (підписи в один рядок; якщо не вміщаються — зменшуються до 11 sp, а не обрізаються): «Через 10 хв» (заповнена `surface`, відступи 12, одразу відкладає) і «Не дзвонити» без іконки (outlined, утримання 1 с); після короткого натиску під обома кнопками на всю ширину панелі на 4 с з'являється «Утримуйте секунду, щоб скасувати дзвінок».
Натиск на саму панель нічого не робить; натиск на картку поза нею — редагування (FR-7b). Така картка стоїть першою в списку. PNG для цього стану ще немає.

**Банер дозволів**: контур `outline`, радіус 20, «Будильник може не задзвонити» + причина, кнопка «Надати дозвіл» (filled) → екран дозволів. Показувати, якщо бракує хоч одного критичного дозволу.

**Сегментований перемикач** (2–3 сегменти): висота 52, контур `outline`, вибраний сегмент `secondaryContainer`. Можна `SingleChoiceSegmentedButtonRow` з M3 з цими кольорами.
- рівень: «●● Будь-яка» / «● Лише червона»;
- тема: «Системна» / «Світла» / «Темна» (з іконками 16).

**Чипи вибору** (хвилини, дні, відкладення): круглі 46–48, контур `outline`; вибраний — заповнений `primary` / `onPrimary`.

**Рядок-значення** (регіон у виборі місць тощо): кружечок 44 `surfaceContainerHigh` з іконкою, над значенням підпис 14 сірий, значення 16/600, праворуч шеврон (перехід) або × (очистити), або + (задати).

**Рядок налаштування** (2026-09-29, як у Samsung): мін. висота 56, назва `bodyLarge` `onSurface`, під нею значення `bodyMedium` кольором `primary` (можна з крапками рівня перед ним); праворуч — нічого, × (очистити) або Switch. Натиск відкриває нижню панель чи діалог з варіантами. Рядки в картці-секції розділені `outlineVariant`.

**Нижня панель вибору** (M3 `ModalBottomSheet`, фон `surfaceContainerHigh`): заголовок `titleMedium`, варіанти, під ними пояснення `bodyMedium` сірим (сюди переїхали підказки з-під полів). Вибір варіанта одразу застосовує його й закриває панель.
- «Чекати, поки триває»: два рядки-радіо «●● Будь-яка» / «● Лише червона», під кожним його пояснення («Жовта — дронова загроза, червона — ракетна» / «Якщо червона зміниться на жовту — це вже відбій»).
- «Після відбою»: чипи 0, 2, 5, 10, 15, 30 + «Якщо за цей час тривога почнеться знову — чекатиму далі.»
- «Відкласти дзвінок на»: чипи 5 … 30 хв + «Задзвонить через цей час, навіть якщо тривога ще триває.»

**Кнопка з утриманням** («Вимкнути», «Сьогодні не дзвони»): outlined, спрацьовує після **утримання 1 с** (з анімацією заповнення прогресу). Постійного підпису під нею немає (2026-09-29): заповнення саме показує, що треба тримати. Якщо палець відпустили раніше — під кнопкою на 4 с з'являється «Утримуйте секунду, щоб …».

**Діалоги**: M3 `AlertDialog`, радіус 28, фон `surfaceContainerHigh`, заголовок `titleLarge`, текстові кнопки праворуч. Деструктивна дія — колір `alertColors.red`.

**Вибір часу** (змінено 2026-09-29): діалог із двома барабанами «години : хвилини» (24-годинний формат, прокручування по колу, як у годиннику Samsung), без перемикача на клавіатуру. У діалозі (крайній час): рядок 48, видно 5 рядків, під вибраним рядком смуга `surfaceContainerHighest`. Вибране число — `onSurface`, сусідні — `onSurfaceVariant` з прозорістю 45 %, далі — 20 %. Для TalkBack кожен барабан — повзунок («Години, 07»). Причина відмови від M3 `TimePicker`: у 24-годинному режимі він губив «після обіду» при зміні хвилин. Малюнок у `03-edit-alarm--time-picker` — орієнтир лише за кольорами.

## 3. Екрани

### 3.1 Будильники (головний) — `01-alarms`, `02-empty--alarms-empty`
Порядок зверху вниз: заголовок → банер дозволів (умовно) → рядок «Розбуди після відбою» → картки будильників (та, що чекає відбою, — першою). FAB «Новий будильник».
Порожній стан: рядок разового режиму лишається, під ним ілюстрація-коло 88 + «Будильників ще немає» + пояснення.

### 3.2 Будильник — редагування / новий — `03-edit-alarm`
- TopAppBar: × «Закрити без збереження», заголовок «Будильник» / «Новий будильник», текстова кнопка «Зберегти».
- Час — одразу барабани «години : хвилини» на самому екрані, як у годиннику Samsung (змінено 2026-09-29): 3 видимі рядки по 72, цифри `displayMedium`, ширина барабана 120; під ними «Спрацює завтра о 06:45», що оновлюється під час прокрутки. Діалог з барабанами лишився лише для крайнього часу.
- Під «Спрацює …» — **план** (2026-09-29), одне речення замість підказок під полями, лише коли «враховувати тривоги»: «Під час тривоги — одразу після відбою» / «… — через 5 хв після відбою» + «, не пізніше 08:00[ наступного дня]». Без регіону — «Регіон не обрано — дзвонитиме як звичайний».
- Рядок над днями (як у Samsung): ліворуч «Повторювати» або, якщо задано дату, «Дата · пт, 9 жовт.» (+ × прибрати); праворуч кнопка-іконка `calendar_today` → M3 DatePickerDialog (`surfaceContainerHigh`, минулі дні недоступні). Під ним 7 круглих чипів Пн…Нд, без підсумку під ними. Вибір дати знімає дні тижня, вибір дня — дату (FR-1a). Якщо дата сьогодні, а час минув, під барабанами червоним «Цей час уже минув — оберіть іншу дату або час», «Зберегти» вимкнене.
- Картка «Враховувати тривоги» зі Switch, без підзаголовка. Якщо увімкнено — рядки налаштування:
  - «Регіон» · «Дім · м. Київ» → екран вибору регіону;
  - «Чекати, поки триває» · «●● Будь-яка» → нижня панель;
  - «Після відбою» · «Одразу» / «5 хв» → нижня панель;
  - «Крайній час» · «Не задано» / «08:00» / «01:00 наступного дня» → діалог вибору часу (під барабанами «Задзвонить у цей час, навіть якщо відбою не буде»); із заданим — × праворуч (FR-6).
- Якщо вимкнено — під перемикачем нічого.
- Картка «Мелодія» / «Вібрація» — ті самі рядки налаштування.
- Внизу (тільки для існуючого) — текстова кнопка «Видалити будильник» (колір red, іконка кошика).
- Новий будильник (FR-7): 07:00, без повторів, тривоги увімкнені, регіон = основне місце, «Будь-яка», пауза 0, без крайнього часу.

### 3.3 Вибір регіону для будильника — `04-alarm-region`
Поле пошуку (56, `surfaceContainer`, повністю округле) → секція «Мої місця» (радіокнопки з назвою і регіоном) → «Інший регіон»: шлях (іконка мапи = «Усі області» › «Київська обл.» › чип «Обухівський р-н», в один рядок) → список: «Увесь Обухівський район» (600) + громади → інфоблок про покриття (таблиця з вимог). Внизу «Готово».
Без збережених місць — одразу список областей (`02-empty--region-no-places`).

### 3.4 Мої місця — `05-places`
Картки: назва (`titleMedium`) + чип «Основне», регіон сірим; кнопка ⋮ → меню:
- «Зробити основним» (не для основного);
- «Перейменувати» → діалог з полем «Назва» (maxLength 24, порожнє не зберігається);
- «Змінити регіон» → повноекранний вибір регіону «Регіон · <назва>»: «Зараз: …», пошук, шлях, список, інфоблок «Будильник 10:00 теж чекатиме на тривоги в новому регіоні.» (якщо місце використовується), «Зберегти» внизу, ← без змін;
- «Видалити» (червоним) → діалог. Для основного: «Це основне місце» + «Зрозуміло». Для інших: «Видалити «Дача»?» + що станеться з будильниками.
FAB «Додати місце». Порожній стан — `02-empty--places-empty`.

### 3.5 Нове місце — `06-add-place`
Крок 1: заголовок «Нове місце», «Крок 1 з 2», вибір регіону (без секції «Мої місця»), «Далі».
Крок 2: діалог «Назвіть місце» з регіоном під заголовком, поле «Назва», «Назад» / «Зберегти». Перше місце автоматично стає основним.

### 3.6 Налаштування — `07-settings`
Картки-секції зверху вниз (рядки налаштування й нижні панелі, 2026-09-29):
1. Рядок «Відкласти дзвінок на» · «10 хв» → нижня панель (5 / 10 / 15 / 20 / 30 хв, за замовчуванням 10; FR-19).
2. «Розбуди після відбою»: рядки «Регіон — основне місце» · «Дім» (→ Мої місця), «Чекати, поки триває», «Після відбою». Без підзаголовка.
3. «Тема»: Системна / Світла / Темна (за замовчуванням Системна) → `ThemeMode`, без підказки під ними.
4. Рядок «Дозволи» → екран дозволів.
5. Примітка про джерело даних і приватність.

### 3.7 Дозволи — `08-permissions`
Заголовок «Щоб будильник точно задзвонив» + пояснення. Картки дозволів (іконка в кружечку; «Дозволити» або «✓ Надано»):
1. Сповіщення — `POST_NOTIFICATIONS`.
2. Будильники й нагадування — точні будильники (див. примітку).
3. Показ на екрані блокування — `USE_FULL_SCREEN_INTENT` (Android 14+ може бути відкликаний).
4. Робота у фоні без обмежень — виключення з оптимізації батареї.
Примітка про Samsung («застосунки, які ніколи не присипляються»). Внизу «Готово» (все надано) або «Пізніше».
Примітка для розробки: якщо використовуєш `USE_EXACT_ALARM` (видається автоматично застосункам-будильникам) — картку 2 можна не показувати. Перевірити на Samsung.

### 3.8 Екран очікування — прибрано (2026-10-03)
Окремого екрана немає. Він повторював те, що вже показують панель очікування (картка, банер разового режиму) і сповіщення: рівень — чотири рази (коло, крапка, чип, причина), «чекаю» — тричі; у паузі «відбій о 07:02 + чекаю 5 хв + задзвоню о 07:07» — один факт трьома рядками. Унікальними були лише дві дії FR-18 і речення про паузу — тепер вони на панелі (розділ 2). Причина тривоги лишилася тільки в сповіщенні: рішення від неї не залежить (FR-28). PNG `10-waiting--*` і `09-one-shot--2-enabled-waiting-screen--*` видалено.

### 3.9 Сповіщення під час очікування — `11-notification`
Постійне сповіщення foreground service (FR-18). Контент: заголовок «Будильник 06:45 чекає на відбій тривоги» / «Разовий режим: чекаю на відбій тривоги», рядок рівня кольором (`redText`/`yellowText`), причина (якщо є), «Дім · оновлено 06:51 · крайній час 08:00».
Дії: **«Через 10 хв»** (одразу відкладає) і **«Не дзвонити…»** — НЕ скасовує, а відкриває застосунок на вкладці «Будильники» (прокрученій угору), де скасування — утриманням на панелі очікування. Натиск на саме сповіщення — те саме.

### 3.10 Екран дзвінка — `12-ring`
Full-screen intent поверх блокування. Зверху: «Будильник 06:45 · Дім», час (`displayLarge`), дата. Під ними блок причини (іконка 64 у кружечку + заголовок `titleLarge` + коротке пояснення, якщо воно щось додає + чип рівня, якщо тривога триває). Пояснення (2026-09-29): відбій — «Відбій о 07:02»; крайній час, тривоги немає — без пояснення (досить заголовка й чипа); немає зв'язку — «Не вдалося перевірити тривогу — тому дзвоню»; застарілі дані — «Свіжих даних немає понад 3 хв — тому дзвоню»; понад добу — «Будильник більше не чекає на відбій». Внизу: «Відкласти на 10 хв» (тональна, 64) і «Вимкнути» (outlined 56, утримання 1 с).
Причини (FR-21): відбій · крайній час (+ чип рівня) · немає зв'язку з сервісом · тривога понад добу (+ чип) · тривоги немає · разовий режим «Немає даних». **Звичайний будильник без тривог — без блоку причини** (`plain-alarm`).

## 4. Сценарій «Розбуди після відбою» — `09-one-shot`
Окремого екрана перевірки немає. Усе відбувається в рядку на головному екрані:

| Стан рядка | Вигляд | Дія праворуч |
|---|---|---|
| Очікує (idle) | без іконки ліворуч, «Розбуди після відбою», «Дім» (рівень і пауза — у налаштуваннях) | кругла тональна кнопка ⏻ (aria: «Увімкнути «Розбуди після відбою»») |
| Перевірка (до 30 с, FR-23) | без іконки ліворуч (текст не зсувається), «Перевіряю тривогу…», «Дім · зазвичай кілька секунд» | × «Скасувати перевірку» в кільці спінера |
| Тривога є | рядок стає **банером** кольору рівня — тією самою панеллю очікування, що й у картці (розділ 2): «Розбуджу після відбою», «Жовта тривога · Дім», кнопки «Через 10 хв» / «Не дзвонити»; Snackbar «Увімкнено. Можна спати — розбуджу після відбою». Переходу на інший екран немає | кнопки панелі |
| Тривоги немає | ✓, «Зараз тривоги немає», «Дім · режим не потрібен» | ⏻ (можна знову) |
| Немає даних | cloud_off, «Немає даних», «Режим не ввімкнено» | «Повторити» |

Скільки тримати повідомлення «Зараз тривоги немає» / «Немає даних» — відкрите питання в requirements.

## 5. Доступність (перевірено на макеті)
- Контраст тексту ≥ 4.5:1 в обох темах (вторинний текст 6.6–7.4:1).
- Усі іконкові кнопки мають `contentDescription` (у макеті — `aria-label`).
- Вибрані стани — `Modifier.selectable/toggleable` з `Role`, а не лише колір.
- Кнопки з утриманням мають альтернативу для TalkBack (custom accessibility action «Вимкнути»/«Скасувати дзвінок»).
- Шрифти масштабуються (sp); на 200% не обрізати час — дозволити перенос або зменшення.
