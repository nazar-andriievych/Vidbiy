# Як перевіряти «Відбій»

Три рівні: юніт-тести (логіка рішення), сценарії на телефоні проти mock-воркера
(поведінка застосунку), живий прогін із журналом (реальні тривоги).

## 1. Юніт-тести

```
.\gradlew.bat test                 # застосунок: RingDecision, WaitStep, OneShot, розбір відповіді
cd server; npx vitest run          # сервер: вебхуки, знімки, свіжість, запобіжники
```

## 2. Інструменти розслідування

**Журнал рішень на телефоні** — кожне рішення будильника й разового режиму: час, регіон,
покривні UID, вік даних, рівні над регіоном, рішення (`decideRing`) і крок (`wait` / `pause` /
`ring` / `retry`). Лише на телефоні, нікуди не надсилається, у резервну копію не потрапляє.

- У debug-збірці: «Налаштування» → внизу «Журнал рішень (debug)».
- З ПК: `adb exec-out run-as ua.vidbiy.app cat files/decisions.jsonl`
- Logcat (лише поки свіжий): `adb logcat -s VidbiyWait VidbiyAlarm AlertsClient`

**Стан на сервері зараз** — без телефона:

```
node tools/check-region.mjs 702          # Буча (громада) → 702, 75, 14
node tools/check-region.mjs Буча
node tools/check-region.mjs 702 --proxy http://127.0.0.1:8787
```

Друкує рівні над регіоном і рішення для «Будь-яка» / «Лише червона».

**Як розбирати «задзвонив під час тривоги»:** знайти в журналі рядок `ring` і попередні `poll`.

| Що в журналі | Що це означає |
|---|---|
| `decision: RING_CLEAR`, `levels: []` | Проксі сказав «тривоги немає». Звірити з офіційним застосунком за цей час |
| `RING_CLEAR`, а в `levels` жовта, `waitFor: RED_ONLY` | Так налаштовано: чекали лише червону |
| `RING_STALE` / `RING_NO_DATA` | Fail-safe: немає свіжих даних (мережа, проксі, ukrainealarm) |
| `RING_ALERT_TOO_LONG` | Рівень оголошено понад добу тому (дата в `levels`) |
| `ring` з `FIRE_DEADLINE` | Крайній час або доба очікування |
| `ring` з `FIRE_SNOOZE` | Відкладений дзвінок: дзвонить незалежно від тривоги (FR-20) |
| `gapSeconds` значно більше 30 | Телефон (енергозбереження Samsung) розтягує опитування |
| `fetch: timeout` / `no_network` / `http_…` | Ця спроба не вдалась; рішення — на попередніх даних (FR-15), їхній вік у `ageSeconds` |
| `confirmedAt` | Момент, який сервер підтвердив, — за ним рядок звіряється із сервером (UTC) |
| тривога в області, а регіон — область | Області бачать лише тривоги, оголошені на всю область; ukrainealarm здебільшого оголошує по районах |

## 3. Сценарії на телефоні (mock-воркер)

Живу тривогу на замовлення не отримаєш, тож поведінку перевіряємо проти локального воркера:

```
cd server; npm run dev -- --ip 0.0.0.0          # MOCK=1 у server/.dev.vars
# debug-збірка з PROXY_URL на адресу ПК (див. app/build.gradle.kts), Windows Firewall — порт 8787
curl.exe "http://127.0.0.1:8787/mock?scenario=alert&uid=75"              # червона в районі
curl.exe "http://127.0.0.1:8787/mock?scenario=alert&uid=75&level=yellow" # жовта
curl.exe "http://127.0.0.1:8787/mock?scenario=alert&uid=75&started_hours_ago=25"
curl.exe "http://127.0.0.1:8787/mock?scenario=clear"
curl.exe "http://127.0.0.1:8787/mock?scenario=down"
```

Будильник ставити на найближчу хвилину, регіон — громада 702 (Буча). Після кожного
сценарію звірити журнал.

| # | Сценарій | Очікуємо |
|---|---|---|
| 1 | `clear` | Дзвонить одразу, причина «Тривоги немає» |
| 2 | `alert` у 702 / 75 / 14 | Мовчить, сповіщення очікування з червоним рівнем |
| 3 | `alert` у 76 (сусідній район) | Дзвонить одразу |
| 4 | `level=yellow` + «Лише червона» | Дзвонить одразу; з «Будь-яка» — мовчить |
| 5 | Під час очікування `clear`, пауза 0 | Дзвонить за ≤30 с, «Відбій» |
| 6 | `clear`, пауза 2 хв; через 1 хв знову `alert`; потім `clear` | Пауза скидається, дзвонить через 2 хв після другого відбою |
| 7 | Червона → жовта при «Лише червона» | Це відбій (FR-13) |
| 8 | `down` під час очікування | Після 60 с — попередження «Немає зв'язку», після 180 с — дзвінок |
| 9 | `started_hours_ago=25` | Дзвонить: «Тривога триває понад добу» |
| 10 | Крайній час під час тривоги | Дзвонить о крайньому часі |
| 11 | Разовий режим: `alert` / `clear` / `level=yellow` з «Лише червона» / сервер вимкнено | Увімкнено / «Зараз тривоги немає» / «Червоної тривоги немає · зараз жовта» / «Немає даних» |
| 12 | Екран вимкнено 10+ хв під час очікування | Опитування не зупинилися (журнал: `poll` кожні ~30 с) |
| 13 | Енергозбереження, «Не турбувати» | Дзвінок чутно |
| 14 | Перезавантаження під час очікування | Очікування відновилось або задзвонив |

## 4. Живий прогін

2–3 дні з реальним будильником і журналом. Щоранку:

1. `adb exec-out run-as ua.vidbiy.app cat files/decisions.jsonl > tmp/decisions-<дата>.jsonl`
2. `node tools/check-region.mjs 702`
3. Порівняти рядки `ring` з офіційним застосунком «Повітряна тривога» і з виводом `check-region`.
