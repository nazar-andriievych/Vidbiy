Відкласти дзвінок на

Для кнопок «Відкласти» на екрані дзвінка і «Подзвони через {{p.snoozeMin}} хв» під час очікування. Задзвонить через цей час, навіть якщо тривога ще триває. Одне значення для всіх будильників.

Розбуди після відбою

Налаштування разового режиму. Крайнього часу в ньому немає.

Регіон — основне місце Дім м. Київ
Чекати, поки триває
Чекати після відбою, хв

Після відбою почекати стільки хвилин, щоб переконатися, що тривога не повториться. Повториться — чекатиму далі.

Тема

«Системна» — як у налаштуваннях телефона, разом із нічним режимом.

Дозволи Сповіщення, точні будильники, екран блокування, робота у фоні

Дані про тривоги — з офіційного API «Повітряна тривога». Без реєстрації, геолокації та аналітики: ваші місця й будильники не залишають телефон. Якщо свіжих даних немає, будильник дзвонить.
